## Use case: Copiloto de análise de documentos empresariais

Um copiloto que ingere documentos de uma empresa, responde com citações, executa análises com agentes ligados por MCP a dados internos, tem avaliação automática e está disponível numa demo pública. O tema pode ser trocado por um problema do teu trabalho.

## Objetivos

- Desenhar a arquitetura de uma solução GenAI de ponta a ponta
- Combinar RAG avançado, agentes, MCP, avaliação e deploy
- Documentar decisões, métricas e custos como num projeto profissional
- Apresentar o projeto no GitHub, no CV e em entrevistas técnicas
