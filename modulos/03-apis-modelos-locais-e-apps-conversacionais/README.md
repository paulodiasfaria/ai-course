## Use case: Chatbot de apoio ao cliente

Um assistente para uma loja online fictícia que responde a perguntas frequentes, mantém o contexto da conversa e pode trocar entre um modelo na nuvem e um modelo local com uma linha de configuração.

## Objetivos

- Usar APIs de LLM com streaming, retries e controlo de custos
- Correr modelos abertos localmente e comparar qualidade, velocidade e custo
- Gerir memória de conversa e resumir histórico longo
- Criar uma interface de chat utilizável em poucas horas
