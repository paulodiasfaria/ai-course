Em código

from anthropic import Anthropic

client = Anthropic()
resposta = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=500,
    messages=[{"role": "user", "content": "Explica o que é um embedding numa frase."}],
)
print(resposta.content[0].text)

Equilíbrio entre previsibilidade e variedade.
