# AI Course

Plano de aprendizagem de GenAI em português: 14 módulos em 5 fases (Fundamentos, RAG, Agentes, Modelos e produção, Portfólio).

Cada módulo terá:
- uma lição interativa em HTML;
- um notebook prático em Python;
- um use case de complexidade crescente, que fica como projeto de portfólio.

Abre [`index.html`](index.html) no browser para ver o currículo completo. Com o GitHub Pages ativo (Settings → Pages → branch `main`), fica disponível em `https://paulodiasfaria.github.io/ai-course/`.
